## Changes and upgrade

- Scroll by pixels through oversized expanded objects, including procedure/function bodies and decoded dynamic SQL,
  retaining virtualization, the existing layout, colors, filters and row gestures.
- Use the supported SSMS themed ComboBox style for the trusted-routine Procedure/Function selector and popup.

Close SSMS and install the newer VSIX. Settings are retained. Upgrades from before 1.1.0 also require the
[qualified-approval migration](../../user/install.md#upgrading-to-110). SQL verdicts, execution policy, settings format,
analysis limits and the text-only boundary are unchanged. The analyzer project changes version metadata only.
