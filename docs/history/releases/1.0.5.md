# Release 1.0.5

[SQL Safety Guard 1.0.5](https://github.com/nagy-ag/SQL-Safety-Guard/releases/tag/v1.0.5) was published on
**2026-11-10 at 09:49:35 UTC**, stable and Latest, at the owner's request. Earlier releases remain available.
GitHub packages remain unsigned and support **SSMS 22.0 and later 22.x releases**, 64-bit, bounded to `[22.0,23.0)`.

## Changes

- Procedure definitions in the editor retain a single definition row and gain a nested **Body — potential effects
  when called** breakdown, using the normal permanent-change, unknown and safe sections.
- Single-clicking an outer or nested object highlights all its statements; double-clicking toggles its details.
  Individual statement buttons highlight only that statement. Several rows can stay expanded across reanalysis.
- Body and safe-section chevrons point down when collapsed and up when expanded. The body explanation paragraph
  is removed. The inspection-only sample and user/developer guides describe the final behavior.
- Deferred findings stay separate from execution verdicts and counts: submitting a definition does not run its body.
  Existing execution classifications, F5 policy, settings formats and the text-only boundary are retained. No SQL
  connection or procedure lookup was added, and unknown/incomplete effects remain visible.
