# Release 1.0.4

Acceptance and publication of release 1.0.4, 2026-11-09: Options scrolling, structured editors for the list settings and
themed title bars. Earlier releases are retained. GitHub packages remain unsigned and support **SSMS 22.0 and later 22.x releases**,
64-bit, bounded to `[22.0,23.0)`.

## Changes

- The integrated Options page scrolls when it is taller than its window. SSMS's sticky copy of the category, which
  contained a second full settings form, now hides itself.
- Safe tables, trusted procedures and environment rules show only counts and a problem line on the page. Edit list opens
  a list with Server / Database / Schema / Name fields, a note, a description and a Try-a-name check; Edit rules opens the
  rules in order with a form per rule; Edit as text keeps the existing text format.
- Dialog title bars follow the SSMS theme instead of staying white in dark themes.
- No analyzer verdict, F5 confirmation, stored settings format or SQL access boundary change. Import and export files
  are unchanged.
