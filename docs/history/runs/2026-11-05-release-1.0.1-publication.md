## Included changes

- Native **Tools > Options > SQL Safety Guard > Uninstall SQL Safety Guard...** action beside Import and Export.
- Corrected Tools submenu parent-group registration. Live popup visibility remains unverified.
- Existing No-default confirmation, host/profile/path binding and adjacent SSMS installer handoff retained.
- Fallback uninstall accepts observed not-installed exit 1002 as well as 2003; other failures propagate.
- Version 1.0.1 in manifest, both assemblies and product registration; SSMS target remains `[22.0,23.0)`, amd64.
- Full ZIP containing the exact standalone VSIX, install/uninstall/helper scripts, instructions, legal notices and signing kit.
- Separate signing ZIP containing `Sign-CompanyVsix.ps1`, `README.txt` and the maintained guide as `SIGNING.md`.
  Its relative guide references become tag-pinned online links. No certificate, key or third-party tool binary is included.

Analyzer classifications, guard policy and production SQL/network boundaries were not changed. The signing helper runs
separately on a company computer and contacts a timestamp service only when signing. It verifies input checksum and
identity/version, rejects existing signatures, checks the current user's code-signing certificate/key, and signs a disposable
copy into a separate output. Its receipt records both hashes and explicitly leaves signature/chain/timestamp verification
pending. It never creates keys, changes trust, installs tools, uploads files or modifies the GitHub download.
