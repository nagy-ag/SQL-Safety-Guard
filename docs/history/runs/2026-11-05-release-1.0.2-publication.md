pane-background deselection and collapse clear the highlight; a refresh does not restore a cleared choice.
Double-click/Enter still navigates without selecting SQL text. The **No permanent changes detected** chevron points
**up when collapsed** and **down when expanded**. The changelog, user guide and product versions are updated.
Analyzer classifications and F5 confirmation policy are unchanged.
