# Release 1.0.5 preparation

The owner requested version 1.0.5, stable and Latest, with the source pushed to main. This snapshot precedes
committed-source packaging and publication; their final results belong in the release record.

The candidate adds inspection of procedure definitions present in the query editor, a normal safety pane nested
inside the definition row, shared single-click highlighting and double-click expansion, individual statement
highlights, and down-collapsed/up-expanded section chevrons. The compact body omits the explanatory paragraph.
The [changelog](../../../CHANGELOG.md) and [user guide](../../user/user-guide.md) describe the final behavior.

Existing execution classifications and F5 policy are retained. Deferred body findings do not enter execution
counts or verdicts, and the production extension still opens no SQL connection or server metadata query.
Bodies of called procedures and SQL built at runtime remain unknown. No color is relaxed by this release.

Prior functional validation is retained in the [procedure-body](2026-11-10-procedure-body.md),
[nested-pane](2026-11-10-nested-procedure-pane.md) and [row-gesture](2026-11-10-row-gestures.md) snapshots.
The last UI candidate passed 1,693 .NET tests, 10 Python tests, 527 inventory freshness checks, both builds,
29 Release pane checks, 21 isolated editor checks plus refresh and 25 isolated procedure checks.
Its normal-profile installation was checked against the built Release payload, settings were preserved
byte-for-byte, and the sample was reopened with a one-row definition and visible nested sections.

Version 1.0.5 metadata is aligned in the manifest, package registration and both assemblies. The next gate must
package the clean committed source, rerun offline tests, rebuild Release and run all three WPF interaction suites.
The earlier live captures exercised the functional candidate before the version bump, through Debug-only hooks;
they do not constitute physical click/key testing or exact downloaded-asset acceptance. No new SQL execution,
server campaign, broad SSMS version matrix, all-theme pass or company signing is claimed.
